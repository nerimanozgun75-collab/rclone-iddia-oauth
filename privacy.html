Privacy policy

This page describes the personal-use rclone and Google Drive archive connection documented by this site.

Use of Google Drive data

Google Drive data is accessed and processed only for the owner’s own archiving, backup, and retrieval purposes. The application is for personal use and is not offered as a service to other users.

Google Drive files and metadata accessed through the connection are not sold, published, or shared with third parties. No unrelated Drive folders or files are intentionally accessed.

Credentials and security

OAuth client credentials, access tokens, refresh tokens, and rclone configuration are kept outside this public repository. They are not included in the site, repository history, or GitHub Actions logs.

Website data

This static site does not intentionally collect personal information, use advertising trackers, or provide user accounts.

Contact

For questions about this personal-use application, use the contact information available through the repository owner’s public GitHub profile.
